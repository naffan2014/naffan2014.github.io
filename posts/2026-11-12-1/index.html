一见微信工作台：左边 Markdown，右边公众号

介绍跑在本机的微信公众号排版工作台「一见」：Markdown 写作、手机壳实时预览、26 套模板与内联样式、一键复制或写入草稿箱，密钥与草稿全部留在自己电脑里。项目地址：https://github.com/naffan2014/yijian-wechat-studio

一见微信工作台：左边 Markdown，右边公众号

　　写公众号这件事，我一直又爱又恨。爱的是它逼着我把想法整理成文，恨的是排版。官方编辑器对习惯了 Markdown 的人不算友好；第三方排版网站要登录、要把内容传到别人服务器，调了半天样式，粘进微信还是掉格式；图片要一张张重新上传，封面要另找工具裁。忍了很久之后，我决定把这套流程自己做一遍，跑在自己电脑上。

　　成品叫「一见」，一个微信公众号排版工作台。一句话概括：左边写 Markdown，右边是按公众号阅读页还原的手机预览，写完一键复制进公众号编辑器，或直接写入草稿箱。

一、先是个本机工具

　　一见没有云端服务。服务只监听 127.0.0.1，局域网里别的设备访问不到；草稿存在本机 data/ 目录，图片存在 uploads/，备份就是复制这两个目录。AppSecret、AI 的 API Key 这类敏感配置只落盘在本机，权限 600，接口响应里永远脱敏。

　　项目开源在 GitHub：naffan2014/yijian-wechat-studio。跑起来也异常省事：零 npm 运行时依赖，不用构建，不用 npm install，克隆下来后 Node.js 18+ 直接：

1
2

node server.js
# 打开 http://127.0.0.1:5188

　　浏览器端用到的转换库（Turndown、DOMPurify、Mammoth 等）全部内置在项目 vendor/ 目录，不访问 CDN，离线也能完成富文本转换。对一个要放草稿和密钥的工具来说，”能离线跑”我认为是基本礼貌。

二、排版：模板、组件，以及不掉格式

　　模板库里有 26 套排版：6 套一见原创，加上 20 套来自花生编辑器的开源主题（MIT 协议），各自保留标题、引用、列表、代码、表格的样式，字号、行距、强调色还能微调。样式中心另有 28 个原创组件——章节标题、导语、卡片、步骤、双栏、关键数字——点一下插入光标处，组件预览会跟随当前主题和强调色。

　　但最重要的不是模板数量，而是所有样式都会转成内联样式。微信编辑器会清洗 <style> 标签和 class，唯一可靠的做法是把样式写进每个元素的 style 属性，预览里看到什么样，粘过去就是什么样。微信还会清洗正文最外层容器的背景色，一见用双层 section 兜底，模板底色和背景纹理在复制、发布后都保得住。

　　编辑器页脚有个实时计数器 HTML x / 20k：微信草稿正文 HTML 上限 20000 字符，用到 80% 变琥珀色，超限变红，发布前直接拦截。被长文卡过上限的人，会懂这个小计数器的好。

三、图标不是图片

　　这是我自己最得意的部分。一见的 115 个图标全部用 Unicode 字符（★ ☑ → ①）和 CSS 图形画成，不是图片，也不是 SVG。好处很直接：不占公众号素材配额，不受图片大小限制，复制到公众号不掉格式，换模板时颜色自动跟着强调色走。

　　「图标工坊」把图标做成了可调的：尺寸、底座、底色浓度、线条字重、间距、不透明度、垂直对齐、颜色，八项控件拖动即时生效，预览台同时给出”单独放大”和”与正文排在一行”两种效果，调好点一下就插入正文。

　　图标之上还有 11 个结构化组件：时间线、图标列表、流程、清单、推荐/避免对比、五星评分……用 ::: 容器书写，每行一条，比如主界面截图右侧手机预览里的时间线，就是这样写出来的：

1
2
3
4
5

:::timeline 一周的桌面节奏
周一 | 清空 | 把上周的杂物全部归位
周三 | 留白 | 只留正在读的一本书
周五 | 复盘 | 写下三件做完的小事
:::

四、从写到发，一条链路

　　写的一侧：网页富文本可以直接粘贴，DOCX、HTML、Markdown、TXT 可以导入，标题、加粗、列表、表格转成 Markdown，内嵌图片自动进本机素材库，并压缩到公众号能接受的大小（JPG/PNG、单张 ≤1MB）；粘贴截图则直接上传插入。

　　发的一侧有两条路：

  • 复制到公众号：富文本复制，保留全部内联样式；配置接口后正文图片自动上传到微信，没配置时只复制文字排版，并明确提示。
  • 发布草稿：自动上传正文图片与封面，写入公众号草稿箱，再到公众平台确认群发。工具只写草稿，不会自动发表——最后那一下发送，应该留在人手里。

　　封面有封面工坊：用文章标题生成 1080 × 460（2.35 : 1）首图，6 种配色、两种版式；选到比例不对的图，会自动打开与公众号后台一致的固定裁剪框，拖动取景、滚轮缩放，裁完存回本机。

　　它还支持贴图，也就是”小绿书”那种图片消息：1–20 张图加一段纯文案，拖拽排序，首图即封面，手机预览按图片消息展示，发布同样写入草稿箱。

　　管多个公众号的话，可以添加多个账号，凭证各自独立，文章绑定账号保存，顶栏一键切换，图库、草稿箱、发布记录都跟随当前账号。其中公众号图库和发布记录是只读的——只看，不改，不删线上内容。

五、AI 是可选的，密钥是本机的

　　AI 美化接任意 OpenAI 兼容接口：DeepSeek、OpenAI、通义、智谱、Moonshot、硅基流动，或者本机 Ollama 都行。排版美化、文字润色、精简提炼三种模式，可以只处理选中的局部，结果先预览再应用，应用后还能撤销。

　　我更喜欢的一个小交互：在正文里选中一句话，旁边浮出「AI 续写」小胶囊，点一下，模型顺着这句话补写一小段，确认后插到后面；贴图文案里同样的操作叫「AI 扩写」。没配模型时胶囊根本不出现——AI 是选项，不是前提。

　　边界也清楚：只有你主动点击时，待处理的文字才会发给你自己配置的模型服务商，除此之外不上传任何地方。

六、微信的规矩，工具替你记着

　　对接过公众号接口的人都知道坑有多碎。一见把微信的硬限制都做成了校验：正文 HTML ≤ 20000 字符、图片仅 JPG/PNG 且单张 ≤ 1MB、标题 ≤ 64 字符、作者 ≤ 8 字符、摘要 ≤ 120 字符；贴图标题 ≤ 32 字符、文案 ≤ 1000 字。公网 IP 不在白名单报 40164，错误卡片会告诉你该把哪个 IP 加进去；账号类型不满足接口权限报 48001，也解释得明明白白。

　　这些细节单看都不难，但叠在一起，就是”写篇公众号”大半的烦躁来源。交给工具，脑子才能留给写作。

七、写在最后

　　一见不想做”新媒体运营平台”，不做涨粉，不做数据分析，不碰你的线上内容。它只是把”写完的东西，安全、快速地变成公众号里该有的样子”这一件事，在本机做透。

　　如果你也和我一样，用 Markdown 写作，在公众号发表，又在意草稿和密钥放在哪里，不妨把一见克隆下来试试。

工具退到写作后面，写作才能走到前面。
